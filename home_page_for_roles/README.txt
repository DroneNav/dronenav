VTTW Home
=========

This module allows administrators to set different homepages for different user roles.

REQUIREMENTS
-----------
* Drupal 9 or Drupal 10

INSTALLATION
------------
* Install as you would normally install a contributed Drupal module.
* Visit /admin/config/people/vttw-home to configure homepage settings for different roles.

CONFIGURATION
------------
1. Navigate to Administration » Configuration » People » Homepage by role
2. Set homepage paths for:
   - Anonymous users
   - Authenticated users (default)
   - Specific roles
